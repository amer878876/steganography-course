# مشروع متقدم: إخفاء نصوص داخل الصور باستخدام LSB

هذا المشروع هو نسخة محسّنة ومهنية من مثال LSB الأساسي. يحتوي على:
- إخفاء نص داخل صورة
- استخراج النص من الصورة
- إضافة كلمة مرور
- حماية الرسالة باستخدام XOR
- تنسيق بطول الرسالة لتجنب الأخطاء في القراءة
- واجهة سطر أوامر جاهزة للتنفيذ

## المتطلبات
```bash
pip install -r requirements.txt
```

## استخدام المشروع
### إخفاء نص داخل صورة
```bash
python stego_advanced.py encode input.png "مرحبا بالعالم" output.png --password mypass
```

### استخراج النص من الصورة
```bash
python stego_advanced.py decode output.png --password mypass
```

## ما الذي تم تحسينه في النسخة المتقدمة؟
1. إضافة طول الرسالة في رأس البيانات
2. فك الشفرة بشكل صحيح بدون قراءة كل البتات في الصورة
3. دعم كلمة مرور اختيارية (`--password`)
4. استخدام XOR كطبقة بسيطة من الحماية
5. تنظيف ووضوح أكثر في الكود
6. جاهز للاستخدام في المشاريع التعليمية أو التجريبية

## ملاحظة مهمة
هذه التقنية تُستخدم غالبًا للتعلم والبحث والإخفاء القانوني للبيانات داخل الصور، وليس كوسيلة غير قانونية أو ضارة.
