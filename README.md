# كورس مختصر: إخفاء البيانات داخل الصور باستخدام LSB

مرحبًا! هذا المشروع يشرح لك بطريقة عملية ومختصرة كيفية إخفاء نص داخل صورة باستخدام خوارزمية LSB (Least Significant Bit) في بايثون.

## ما هو LSB؟
LSB هو أسلوب بسيط جدًا لكنه عملي جدًا لإخفاء البيانات داخل الصور. الفكرة الأساسية:
- الصورة تتكون من بكسلات
- كل بكسل يحتوي على ثلاث قيم رئيسية: R, G, B
- كل قيمة يمكن تغيير أقل بت فيها (Least Significant Bit) بدون أن يلاحظ الإنسان الفرق في الصورة
- نستخدم هذه البتات لتخزين رسالة أو نص داخل الصورة

## لماذا هذا مهم؟
- تعلم أساسيات steganography
- فهم التعامل مع الصور في بايثون
- بناء مشروع عملي يمكن تنفيذه في دقائق
- قاعدة ممتازة لتوسيع المعرفة لاحقًا إلى watermarking أو DCT أو تقنيات أكثر احترافية

## ما الذي ستتعلمه في هذا المشروع؟
1. التعامل مع الصور باستخدام PIL (Pillow)
2. قراءة وكتابة البكسلات
3. تحويل النص إلى بايتات وبتات
4. إخفاء البيانات داخل الصورة
5. استخراج البيانات من الصورة
6. بناء واجهة سطر أوامر CLI

## هيكل المشروع

- `requirements.txt` — المكتبات المطلوبة

## المتطلبات
- Python 3.9+
- Pillow

## تثبيت المكتبات
```bash
pip install -r requirements.txt
```

## استخدام المشروع
### 1) إخفاء نص داخل صورة
```bash
python stego.py encode input.png "مرحبا بالعالم" output.png
```

### 2) استخراج النص من الصورة
```bash
python stego.py decode output.png
```
